## Summary
Aiden reports multiple interaction issues on iOS (iPhone): (1) tapping like on a message gives no visible feedback - the like is not displayed; (2) on the latest version, tapping a message location link often jumps to a very old message instead of the target; (3) the keyboard does not auto-populate - the user must tap the input box once before the keyboard appears.

## Steps to reproduce
1. Open a chat on iOS (iPhone)
2. Tap the like/reaction button on a message - no reaction or feedback appears (inferred)
3. Tap a message location link to jump to a specific message - the app jumps to a very old message instead (inferred)
4. Tap the input box - the keyboard does not appear automatically; a second tap is required (inferred)

## Expected result
Likes should display immediately after tapping; message location should jump to the target message; the keyboard should auto-populate when the input box is focused.

## Actual result
Likes are not visible after tapping; message location jumps to a very old message; the keyboard requires an extra tap to appear.

## Severity
- **Level**: Medium
- **Frequency**: Intermittent

## Environment
- **Platform / OS / Browser**: iOS (iPhone)

## Additional context
- **Feature area**: Messaging / UI

## 摘要
Aiden 反馈 iOS 端（iPhone）存在多个交互问题：点赞后看不到反馈/不显示；最新版本定位消息时常跳到较旧的消息；输入框需额外点击一次才会弹出键盘。

## 复现步骤
1. 在 iOS（iPhone）上打开一个聊天
2. 点击某条消息的点赞按钮 - 无反馈或未显示（推断）
3. 点击定位消息链接跳转到某条消息 - 却跳到了很旧的消息（推断）
4. 点击输入框 - 键盘未自动弹出，需再点击一次（推断）

## 预期结果
点赞后应立即显示；定位消息应跳到目标消息；聚焦输入框时键盘应自动弹出。

## 实际结果
点赞后看不到；定位消息跳到很旧的消息；键盘需额外点击一次才弹出。
