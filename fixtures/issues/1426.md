## Summary
In the chat window, when a user selects only part of a message's text and right-clicks > 'Copy', the clipboard receives the ENTIRE message text instead of the selected portion. This was found during QA testing of issues #1350/#1316 on 2026-09-01 (chat web, v1.6.7, Edge + Chrome).

## Steps to reproduce
1. 1. Open https://chat-test.teamily.ai/chat and log in
2. 2. Open any conversation (single or group chat) with a message containing long text
3. 3. Select only PART of the message text (e.g. the first few characters) with the mouse
4. 4. Right-click on the selected text and click 'Copy' in the context menu
5. 5. Paste into any editor (Notepad, another chat input) and inspect the copied content

## Expected result
Only the selected portion of the text is copied to the clipboard.

## Actual result
The ENTIRE message text is copied, regardless of the selection range.

## Severity
- **Level**: Medium
- **Frequency**: Always

## Environment
- **Platform / OS / Browser**: Web / v1.6.7 / Microsoft Edge, Chrome

## Additional context
- **Feature area**: Messaging / Chat UI

---

## 摘要
聊天窗口中，用户只选中消息文本的一部分后右键点击'复制'，剪贴板得到的是整条消息的完整文本，而非选中的部分。该问题于 2026-09-01 在 #1350/#1316 的 QA 测试过程中发现（chat 网页端，v1.6.7，Edge + Chrome）。

## 复现步骤
1. 1. 打开 https://chat-test.teamily.ai/chat 并登录
2. 2. 进入任意会话（单聊或群聊），选择一条包含较长文本的消息
3. 3. 用鼠标只选中该消息文本的一部分（例如仅前几个字）
4. 4. 在选中文本上右键，在弹出的上下文菜单中点击'复制'
5. 5. 粘贴到任意位置（记事本、另一个对话框输入框）查看复制内容

## 预期结果
剪贴板只包含用户选中的那部分文本。

## 实际结果
剪贴板包含整条消息的完整文本，与选中范围无关。
