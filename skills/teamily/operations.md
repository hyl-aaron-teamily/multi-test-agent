# 操作规范

1. **标定期**（`skill calibrate`）：唯一读取页面结构 / uiautomator 层级的时机。产物是坐标与参考截图。
2. **准备期**（每份 Issue 一次）：启动/打开一次 → 首页参考比对（失效即停）→ 模型选动态目标并冻结坐标 → setup。
3. **循环期**：只按坐标操作；相邻两次输入的开始时间 ≤ 950 ms（含设备侧耗时）；每步不截图、不发额外 adb 命令。
   - 异常门：Android 一条 logcat 流（崩溃 / ANR / 进程死亡 / 离开 App / App E 行=可疑）；Web 页面事件（pageerror / crash / 跳到登录或外域；console error 只记可疑）。
   - App 在后台被系统回收（`has died` 且前台不是本 App）不算崩溃。
4. **检查点**：每轮末尾一次截图（仅当计划有画面检查）→ 参考区域笔画比对 → 不一致才调视觉模型（`onlyOnAnomaly`）。不在聊天页 = 操作偏离：重进，不计命中。
5. **视觉模型**：准备期定位会话内目标；检查点核对；`ai` 类验收项。每次调用都计数进报告。
6. **禁止**：注入页面脚本、读源码、调试版、App 内部钩子；循环中发送会打扰他人的消息（通用模板只滚动、不发送）。
