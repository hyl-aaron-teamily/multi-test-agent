# W2-3 同事验收说明（§10.2「人能看懂」）

目的：确认一位**没参与开发**的同事只看计划审核页，就能说清这个计划要做什么、会影响什么。不让 LLM 代测（F9）。

## 准备（开发者）

1. 启动平台：`pnpm platform`，浏览器打开首页 http://localhost:3210 。
2. 确认 2010、1903 有草稿（首页 Issue 表里「草稿 v…」；没有就点「生成草稿」）。
3. 给同事两个链接（每个计划单独计时）：
   - http://localhost:3210/plan.html?id=2010%2Fmain%3Aandroid-app%40v1
   - http://localhost:3210/plan.html?id=1903%2Fmain%3Aandroid-app%40v1
   （版本号以首页显示为准。）
4. 不解释、不回答问题；同事可以把鼠标停在带虚线的词上看解释。

## 同事作答（每个计划 5 分钟内，不提问）

| # | 问题 | 同事的回答 |
|---|---|---|
| 1 | 最多会发几条消息？ | |
| 2 | 发到哪个会话？ | |
| 3 | 会改手机上的哪些设置？ | |
| 4 | 怎样算「已复现」？ | |
| 5 | 哪些地方不确定？ | |
| 6 | 大约要多久？ | |

用时：____ 分钟　　是否提问：是 / 否

## 判分（开发者，对照页面上的内容，不对照本文）

- 1：与「会影响什么 → 最多发送消息」一致（2010 为 0 条；1903 为页面所写的上界）。
- 2：2010 答「不发送 / 只在自己的 Personal AI 会话里操作」；1903 答页面写的群名。
- 3：答「额外修改的手机设置：无」，并能说出环境配置项（Taplus 黑名单、充电常亮）是注册环境时同意过的。
- 4：能说出「每轮检查 X 不成立算命中，连续 3 轮命中才算已复现」，以及偏离轮不计入。
- 5：至少说出页面「哪些地方不确定」里的一条（如改写结果由服务端 AI 决定、替代执行）。
- 6：落在页面给的区间里。

6 问全对、5 分钟内、未提问 = 通过。结果补记到 `docs/w2m3-acceptance.md` §10.2（日期、同事、用时、每问对错、页面上让人卡住的地方）。
