# W2-4.1 新 Web 控制台：同事验收（H8）

请一位没参与开发的同事做，约 20 分钟。准备：在测试电脑上运行 `pnpm platform`，约 1 分钟后打开 http://localhost:3210 。手机保持解锁。

每一页请回答五个问题：**要做什么 / 正在做什么 / 结果是什么 / 可信吗 / 下一步做什么**。答不出、要猜、看不懂的词，原样记下来。不需要懂代码。

| # | 操作 | 要回答的问题 | 看懂了吗（是 / 否） | 看不懂的地方（原话） |
|---|---|---|---|---|
| 1 | 打开「总览」 | 哪些环境能用？有没有在跑的任务？最近一个任务的结论是什么？ | | |
| 2 | 「新建任务」→「自然语言 · 探索」，写「打开通知铃铛看看有哪些分类」，端选桌面网页，点「先检查」再点「开始」 | 它会不会发消息？最多跑多久？ | | |
