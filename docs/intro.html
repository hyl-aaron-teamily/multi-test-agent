Capabilities

好用在哪

偶发问题的复现条件往往说不清，甚至不一定能复现。测试台的做法是：让 AI 按计划换着花样反复试，同时给每一次尝试都设好上限、留好证据。

一句话需求 → 测试计划
→ 真机执行 → 报告
模型规划 + 关键词兜底 步数 / 时长双上限 冷热启动交替 发现即停 --plan 复用计划

规划器把需求拆成目标区域、入口、每轮场景动作（含切后台、快速连点、连发消息）、检查项和建议上限。 执行器按轮跑：启动 → 进入 → 场景 → 随机探索 → 检查 → 视觉探测 → 帧率统计。 检查项间隔 3 秒问两次都为否、且能从截图判断才算失败；没发现问题就如实写「未复现」。

AI 探索遍历

只给包名，AI 自己识别可交互元素、按界面状态去重、优先探索导航入口；有界步数，崩溃当场留证。

pnpm autotest explore --package …

Monkey 固定 seed

伪随机事件流 + logcat 并行监控，崩溃与 Monkey 日志按时间窗交叉验证，复现命令可直接复制。

pnpm autotest monkey --seed 12345

即时重放

每个动作按可重放格式记录，同时环形录屏；一旦出问题，导出出事前约 90 秒的视频与操作序列，按原顺序重放 N 次。

pnpm autotest replay …/replay.json --times 3

IM 界面层收发

im-loadtest 的命令、指标与 SLO 搬到界面：真打字、真点发送，气泡在屏幕上出现才计时；补上重复气泡与乱序。

pnpm autotest imui run --client …

Minimal Path

最小实践 · 五步复现偶发问题

从零到「AI 在真机上替你跑完一轮复现，并给出带证据的报告」，最少五步。左右切换查看。

01

连上真机

手机打开 USB 调试并授权；装好 platform-tools 后确认设备在线。

$ pnpm autotest devices
4f2ebdf2　　　　device　　2211133C
02

配置视觉模型

复制 .env.example 为 .env，填一个 OpenAI 兼容的视觉模型接口。规划与执行共用它。

MIDSCENE_MODEL_BASE_URL=…
MIDSCENE_MODEL_API_KEY=…
MIDSCENE_MODEL_NAME=qwen3-vl-plus　MIDSCENE_MODEL_FAMILY=qwen3-vl
03

启动控制台

浏览器打开后，左侧能看到设备状态；任务由设备池排队分配，不会抢同一台手机。

$ pnpm platform
[platform] console → http://localhost:3210　(maxConcurrent=1)
04

用一句话提需求，设好上限

选「自然语言任务」，填包名和需求，按需设步数与时长上限；不填就用计划建议值，平台硬上限 300 步 / 120 分钟。

需求　聊天时偶发闪退，你试试能不能重现
计划　reproduce · 7 个场景动作 · 5 项检查 · 帧率采集
上限　60 步 / 20 分钟　看门狗 到点 + 2 分钟强制写报告
05

看报告，必要时重放

报告给出结论、计划、每步轨迹、问题截图；出现崩溃时附 replay 包，可按原顺序重放验证。

⚠　crash　闪退：…　replay bundle → replay-1/ (3 video segments)
$ pnpm autotest replay …/replay-1/replay.json --times 3

Boundaries

能力边界

测试台如实反映约束，不掩盖。用之前先知道这些。

◔
AI 动作慢

每步 3–160 秒。偶发问题需要给足时长上限；缓存只在复用同一计划时生效，Android 上只缓存规划、不缓存定位。

≡
界面层收发吞吐低

imui 在 Android 上约 20 秒一条（聚焦、清空、输入、核对、发送、确认），观察分辨率约 3 秒。要大流量请用 imload。

⇄
观察端投递尚未真机验证

需要第二个客户端：第二台手机、模拟器，或运行一次 imui login 手动登录 chat-web。Web 客户端目前只过了离线自测。

!
判定会有误报

视觉检查与禁点名单基于模型和关键词。两类真机误报已修正，报告仍需对照截图复核。

⚙
Monkey 不要对生产账号跑

随机点击无法约束，可能发消息、改设置。生产 App 请用自然语言任务或 AI 探索，Monkey 用测试账号。

◎
CI 与 WebView 未完成

工作流只做了语法检查，未在真实 runner 上跑过；WebView / 小程序没有接入，WebView 内容只能靠截图操作。
